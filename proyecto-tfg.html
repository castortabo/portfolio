Sistema IoT para Monitorización Térmica Asistencial con ESP32 (TEMP IoT)

Proyecto de Fin de Grado (TFG) por Cástor Taboada Miranda

ESP32 IoT Sensores Wi-Fi Dashboard ThingSpeak

Resumen del Proyecto

Sistema IoT de bajo coste diseñado para la monitorización térmica en tiempo real en entornos asistenciales y sanitarios, enfocado en mejorar la calidad de vida de personas dependientes. Proporciona una solución accesible, no invasiva y de despliegue rápido para centros de cuidado, residencias y supervisión domiciliaria.

Arquitectura Hardware

La integración física está optimizada para mantener un consumo energético mínimo y lecturas constantes de alta fidelidad:

  • Microcontrolador ESP32: Doble núcleo con conectividad Wi-Fi (802.11 b/g/n) y bajo consumo para procesamiento embebido.
  • Sensor Digital DS18B20: Medición térmica de alta precisión con bus 1-Wire, calibración de fábrica y tolerancia mínima.
  • Módulo de Alimentación Autónomo: Regulación de voltaje protegida para garantizar operatividad continua frente a cortes eléctricos o uso móvil.

Infraestructura Software y Cloud

Ecosistema digital completo para la ingesta, análisis y alerta en tiempo real:

  • Registro en Tiempo Real: Envío de telemetría continua de temperatura vía HTTP REST/MQTT.
  • Integración Cloud con ThingSpeak: Canal IoT en la nube para almacenamiento de series temporales, visualización gráfica y análisis analítico.
  • Dashboard Multiplataforma: Panel de control accesible desde navegadores web en ordenadores, tablets y smartphones.
  • Sistema de Alertas Automáticas: Notificación inmediata al personal o familiares en caso de superación de umbrales críticos de temperatura.
